# Fuentes y créditos

- Juego y universo: Stardew Valley, de ConcernedApe. https://www.stardewvalley.net/
- Referencia en español: https://es.stardewvalleywiki.com/Stardew_Valley_Wiki
- Referencia en inglés: https://stardewvalleywiki.com/Stardew_Valley_Wiki
- Cada guía y cada registro de catálogo conserva su fuente específica en el campo `source`.
- Guías y descripciones: redacción original de este proyecto a partir de hechos y mecánicas del juego. No se ha replicado el texto íntegro de la wiki.
- Ilustraciones `farm-hero.png` y `ligia-oscar.png`: generadas con la herramienta integrada de generación de imágenes de Codex, con las fotos que Oscar facilitó como referencias de identidad. No se almacenan las fotos originales en el repositorio.
- Nunito: Vernon Adams, Cyreal y Jacques Le Bailly. Distribución Fontsource; SIL Open Font License 1.1.
- Pixelify Sans: Stefie Justprince. Distribución Fontsource; SIL Open Font License 1.1.
- Lucide: comunidad Lucide, licencia ISC.
- Emoji: representación nativa del sistema operativo.

Consulta editorial: 2026-10-25. Base de juego: 1.6. Los datos son una selección, no una garantía de cobertura de toda versión, plataforma o mod.

## Comprobaciones

`npm test` verifica identificadores únicos, fuentes de referencia, categorías, rangos de cumpleaños, 34 vecinos y 12 candidatos al matrimonio, búsqueda sin tildes y casos límite de la calculadora.

`npm run build` compila la distribución estática. Las funciones no dependen de una API remota.
