# Python fundamentals

Small, independent scripts for practicing the language. They use the Python standard
library and are not packaged as one application.

`basics/` progresses through variables, strings, arithmetic, comparisons, input,
type conversion, logic, conditionals, lists, loops and `math`. Additional practice
lives in `basics/ejercicios/`; `basics/app.py` is a minimal hello-world entry point.

From this directory, for example:

```powershell
python basics/01-variables.py
python basics/05-input.py
```

Some scripts ask for console input. Run one exercise at a time and inspect its code
alongside the output. Python projects that need external libraries live in the AI
area and document their own environments.
