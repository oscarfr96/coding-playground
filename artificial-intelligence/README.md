# Artificial intelligence

Courses and experiments grouped by learning area. Each subproject has an independent
environment; Python requirements are not shared across this directory.

| Area | Contents |
| --- | --- |
| [LangChain and LangGraph](langchain-langgraph-python/README.md) | Reviewed progression from prompts to RAG, state graphs, checkpoints and memory; five local apps |
| [Advanced AI](inteligencia-artificial-avanzada/README.md) | CartPole agent–environment loop with a hand-written policy |
| [Machine learning](machine-learning/README.md) | F1 experiments, polling-error analysis, regression and fuzzy rules |
| [Deep learning / earlier AI apps](deep-learning/README.md) | Full-stack Alice RAG chatbot with FastAPI and React |

The folder names reflect the repository's learning history. The RAG chatbot uses
pretrained language models; it does not train a neural network from scratch.
