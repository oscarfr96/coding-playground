# Datos de demostración

Los textos de esta carpeta se han creado como material ficticio para las demos:
dos contratos simplificados, un perfil profesional y una transcripción de reunión.
No contienen datos de personas reales ni constituyen plantillas jurídicas.

Los PDFs, el vídeo y las bases originales se conservan únicamente en
`local_data/originales/`, excluido de Git. Para practicar con tus PDFs, usa
`document_loaders --path` o `vector_stores --path` y una ruta bajo `local_data/`.
