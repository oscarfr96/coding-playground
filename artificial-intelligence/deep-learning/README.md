# Earlier AI application experiments

[Alice RAG chatbot](langchain-rag-alice-chatbot/README.md) combines a Python/FastAPI
backend, Chroma document retrieval and a React frontend. It is an earlier learning
experiment using pretrained models, not a neural-network training project.

Its LangChain imports and dependency setup predate the reviewed
[LangChain/LangGraph course](../langchain-langgraph-python/README.md). Start with the
course for a locked environment, tests and current examples; consult the chatbot
README for the earlier full-stack integration and its compatibility limits.
